## 📋 Test Case Template Design

Each worksheet inside **`assignment-1.xlsx`** is structured according to the standard QA Test Case template design:

### 1. Header & Metadata Section
* **System Name**: E-Commerce Application
* **Objective**: Functional and Integration Verification per feature module
* **Metadata Fields**: Date, System, Objective, Function, Version/Release, Status, Tested by, Environment, Test ID, Req. ID, Screen, and Test Type.

### 2. Test Execution Table
Each test case contains detailed, realistic execution steps with the following attributes:
* **Step Sr.**: Sequential Step Numbering (`01`, `02`, ..., `10`, `End`)
* **Step Description**: Concise action description
* **Path & Action**: Step-by-step navigation path and click triggers
* **Test Data**: Input variables, credentials, and parameters
* **Expected Results**: Intended system response
* **Actual Result Pass / Fail**: Execution result (`Pass`)
* **Comments**: Notes and verification status

## 🚀 Navigation & Usage

1. Open **`assignment-1.xlsx`** in Microsoft Excel or compatible spreadsheet software.
2. The first tab, **`Test Cases Index`**, contains a master list of all 53 test modules.
3. Click the **"Open [Sheet Name]"** link in the Index sheet to jump directly to any formatted test case.
